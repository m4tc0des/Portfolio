### [API de Login com Identity e JWT](https://github.com/m4tc0des/ApiLoginIdentityJwt)
API desenvolvida em **ASP.NET Core** para cadastro e autenticação de usuários, aplicando conceitos de segurança com **ASP.NET Identity** e geração de tokens **JWT**.

**Tecnologias utilizadas:**
- C#
- .NET Core / ASP.NET Core
- ASP.NET Identity
- JWT (JSON Web Token)
- Swagger / Postman para testes
- Git/GitHub para versionamento

**Principais funcionalidades:**
- Cadastro de usuários com validação de senha
- Login com autenticação via JWT
- Testes de endpoints documentados no Swagger
- Estrutura organizada com DTOs, Services e Controllers

**Objetivo do projeto:**
Praticar autenticação moderna em APIs REST, aplicando boas práticas de segurança e explorando o fluxo completo de login/cadastro com tokens JWT.
